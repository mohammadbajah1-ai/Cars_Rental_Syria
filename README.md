# Car Rental Website – وظيفة تصميم وتطوير تطبيقات الوب (F25)

## محتويات المشروع

| الملف | الوظيفة |
|---|---|
| `home.html` | الرئيسية: أسماء الطلاب (عربي/إنكليزي) + الأرقام الجامعية + رابط النشر + ملاحظات |
| `AboutUs.html` | من نحن: معلومات المكتب + التواصل + الفروع وأوقات الدوام |
| `Cars.html` | جدول السيارات (5 سيارات بالصور) + نموذج الحجز + نافذة النتيجة |
| `style.css` | ملف التنسيق الوحيد لكل الصفحات |
| `myFunctions.js` | ملف الجافاسكريبت الوحيد (كل التوابع: التحقق، الحساب، jQuery) |
| `jquery.min.js` | مكتبة jQuery 3.7.1 (نسخة محلية حتى يعمل الموقع بدون إنترنت) |
| `images/` | صور SVG صغيرة (أقل من 1 KB لكل صورة) |
| `AI_Feature_Report.docx` | تقرير الـ AI Feature (أقل من صفحتين) |
| `names.txt` | ملف الأسماء المطلوب رفعه مع الملف المضغوط |

## ما يجب تعديله قبل التسليم

1. في `home.html`: استبدل أسماء الطلاب والأرقام الجامعية (4 صفوف، أضف/احذف حسب عدد المجموعة).
2. في `home.html`: ضع رابط النشر الحقيقي (في فقرة «رابط النشر على الإنترنت»).
3. في `names.txt`: اكتب (رقم الطالب - الاسم الكامل - رقم الصف).
4. في `AI_Feature_Report.docx`: يمكن إضافة أسماء المجموعة في سطر «المجموعة».

## النشر المجاني

أسهل طريقة GitHub Pages: أنشئ مستودعاً باسم `car-rental`، ارفع الملفات (بنفس البنية) ثم فعّل
Settings ← Pages ← Branch: main. يصبح الرابط `https://USERNAME.github.io/car-rental/home.html`.
بدائل: Netlify Drop أو InfinityFree.

## التسليم

- ضع كل الملفات في ملف مضغوط واحد اسمه أرقام الطلاب (مثال: `201001_201002_201003_201004.zip`).
- يرفع **كل طالب** الملف بنفسه على Moodle قبل الموعد بيومين على الأقل.

## قواعد التحقق المطبقة في النموذج

| الحقل | إلزامي؟ | القاعدة |
|---|---|---|
| الاسم الكامل | لا | أحرف عربية فقط، كلمتان على الأقل |
| الرقم الوطني | نعم | 11 رقماً، أول خانتين من 01 إلى 14 |
| تاريخ البداية | نعم | `yyyy-mm-dd` (يُقبل أيضاً `dd-mm-yyyy`) وتاريخ موجود فعلاً |
| تاريخ النهاية | نعم | نفس الصيغة ويجب أن يكون لاحقاً لتاريخ البداية |
| الموبايل | لا | Syriatel: 093/098/099 — MTN: 094/095/096 (10 أرقام، ويقبل +963) |
| البريد | لا | صيغة بريد صحيحة |

- عدد الأيام = الفرق بين تاريخ النهاية وتاريخ البداية.
- المبلغ = مجموع (السعر اليومي × عدد الأيام) لكل سيارة مختارة.
- إذا كانت المدة **أكثر من 7 أيام** يُطبَّق خصم 10%.
